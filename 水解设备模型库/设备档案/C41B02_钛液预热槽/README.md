# C41B02 钛液预热槽模型档案

2026-11-06 以本槽为样本优化三维预览。使用正交相机、平滑法线和柔和高光，轴测、侧视和俯视共用一个显示比例。图中比例尺随滚轮缩放更新。预览读取 v1.4 装配模型。

v1.4 装回标注侧视搅拌器的双端对称中间轴。中间轴上端接联轴器套筒，下端在 Z=4888.279 mm 接原槽内轴。原轴下半段与两层叶轮沿用原模型，可在 3D 页面选择「轴与叶轮」一并查看。

v1.3 槽顶采用标注侧视搅拌器 v0.3 的电机、联轴器和开窗支架。以槽盖上表面 Z=5055 mm 为安装面，整套统一缩放 1.065 倍，电机顶仍为 Z=7185 mm。槽内轴和两层叶轮沿用原模型，驱动端在 Z=6380 mm 接合。

v1.2 参照搅拌驱动详图收细电机，并把电机下方的环组做成三层。上、中、下环的示意外径分别为 Ø490、Ø550、Ø640 mm，槽顶至驱动顶仍按 2185 mm。

v1.1 更新模型展示配色和曲面明暗，3D 页面使用深度渲染。颜色用于区分槽体、驱动和基础，几何取自确认版。由工作区运行 `python 水解桥架工程/tools/source/build_tank_mixer.py --polish-archive` 重建模型文件。

按用户提供的侧视图及确认尺寸归档。模型本体为 Ø5500 × 5000 mm 直筒平底槽，槽盖、开窗支架和驱动组件均包含在模型中。搅拌器高出槽体顶部基准 2185 mm，总高 7185 mm，基础与支脚为独立部件。

- `C41B02_钛液预热槽.glb`：分件三维模型，GLB单位米、Y向上。
- `C41B02_钛液预热槽.obj`：分件三维模型，OBJ单位米、Z向上。
- `3d.html`：离线交互3D浏览，可隔离显示各建模阶段。
- `index.html`：正立侧视图。
- `参数.json`：尺寸及假设记录。

本档案不覆盖设备模型库既有的 C41B02A–E 资料；后续确认要替换该系列旧几何时再单独修订模型库目录与实例。
