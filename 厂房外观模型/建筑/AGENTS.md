# 完整建筑维护入口

建筑只在本目录维护，先读 README.md、building.json 与 data/建模依据.json。tools/build_building.py 生成唯一 model_data.js，独立浏览和水解总装共同引用它。不要在总装内再造简化外墙、门窗或楼板。

源图纸只读。东X、北Y、上Z，毫米，Z0=EL100。源建施平面外墙原点向柱轴转换X/Y各减325mm，导出网格已转换，引用时不得重复平移。主体88根粗柱不改；此前移除的通高400mm细柱不恢复，只按房间结构资料补5.970–9.900m局部柱。

楼梯按SE/NW与NE/SW两组建模，分别至12m/23m；踏步、平台、TZ、栏杆及平面位置保留源句柄。吊装孔仅按内轮廓真切孔，二层3处、三层2处，吊装区不当孔。房间边界/门洞来源保留，未给出的精装修、吊顶和家具不补造。

改建筑不改设备网格、设备就位表或桥架。重建后运行 tools/test_building.py，更新浏览器检查与预览，执行 tools/project.py snapshot/check。总装因引用新网格需更新来源指纹与检查；原桥架/主体柱报告不代表新增楼梯、房间和梁架均已完成碰撞检查。
