# 厂房完整建筑模型

本目录是建筑唯一维护入口。`model_data.js` 同时供独立浏览和水解总装加载；总装不再保留另一份简化建筑网格。完整立面规则沿用原独立外观：133扇窗、13樘门，含十字分格、百叶、工业门内嵌小门及下部网格。主体梁架、屋面、女儿墙与屋面楼梯间一并显示。

## 浏览

在仓库根目录启动 `python -m http.server 8000`，打开 `http://localhost:8000/厂房外观模型/建筑/`。无外网资源依赖。

可切换外墙、梁柱、楼梯、房间、房间顶板、楼板及主屋面；“局部查看”提供四角楼梯、一楼/二楼房间、各层吊装孔。“内部查看”隐藏外墙、屋面和楼板。支持北向俯视、标高区间、水平剖切、旋转、Shift平移和缩放。东南低角度复位3°，俯角0–90°。

## 参考图视觉样式（仅显示）

独立建筑与总装共同加载 `building_style.js`：深色纯背景、灰蓝哑光墙面、青色门窗细线、深色门扇与浅色细节。梁柱、楼板边缘与墙面的色调接近，弱化立面网格。东南默认视角俯角3°，按当前视口适配整栋建筑；旋转与相交项局部查看仍可自由使用。

材质和灯光仅在浏览器中应用，不回写 `model_data.js`、结构参数或总装就位表。门窗线条复用现有线条网格的端面中心，增加一像素的显示线以保证远看清楚；线条经过深度测试及标高裁切，不修改门窗尺寸、构件坐标或网格。设备与桥架的材质、照明及就位参数保持原样。

墙柱共面采用 `polygonOffset(-1,-8)` 稳定优先显示连续外墙，抑制外立面的柱网；内部查看与单独梁柱查看仍显示完整构件。楼板不再使用会在低俯角下穿透立面的斜率深度覆盖层。`tools/test_display.py` 使用高对比样例检查深度冲突，避免相近的墙柱配色遮掩问题，并检查两个实际浏览器的四面旋转。记录见 `data/立面显示检查.json`，预览见 `previews/`。

## 坐标与来源

轴网44,000×72,000mm，外墙边界44,650×72,650mm。东+X、北+Y、上+Z，模型毫米制；Z0=EL100。建筑平面外墙原点转柱轴坐标时X/Y各减325mm，导出网格已经转换，总装引用时不再平移。

原始建施图、结构施工图保留在 `原始资料/`，不覆盖。`building.json` 与 `data/建模依据.json` 保存原图SHA256、部件定位、平面原点、源句柄、标高与待核边界。

## 四角楼梯

- 东南4#、西北1#为A组，至+12m（EL112）。
- 东北2#、西南3#为B组，继续至+23m（EL123）屋面。
- 低区平台按0、2、4、6、8、10、12m；B组高区按14.2、16.4、18.6、20.8、23m。
- 踏步水平进深260mm，2m梯段12级、2.2m梯段13级；包含实体踏步/斜底、平台、栏杆扶手与TZ附属柱。两组各按对角平面方向布置。
- 对应建施详图/剖面如A4575、A4758、A4D0B、A4F2D，结构详图如5139C、51D8D、51E4E、54908。屋面楼梯间有FM1522出入口，不再用封死的实心块替代。

## 房间与附属柱

首层西侧补变压器室、配电室、机具间；二层东侧补机柜室、工具间、取样仪器间。隔墙按建施WALL层的成对边线重建，保留实际门洞，并补门扇和门上过梁。

地坪按图：变压器室+0.100m，配电室/机具间+0.300m，机柜室+6.300m，工具间/取样仪器间+6.000m。二层房间屋面+9.900m，对应顶高3900标注及结构屋面图；首层隔墙接二层板底，不另造无依据的吊顶。

88根主体粗柱的位置、截面不变。此前删除的10根通高400mm细柱不恢复；依据房间范围与5.970–9.900m柱平面补8根局部柱，另补楼梯TZ柱。原98根柱提取记录仍保留在 `结构立柱数据.json`，与当前建筑显示范围分开。

## 楼板与吊装孔

EL100、106、112、123层板均为真实几何板面，不用颜色贴片模拟孔洞。二层南侧3处吊装孔，三层南侧2处，内净尺寸均为3000×2850mm；源内轮廓句柄分别为383/39A/3B9及543/547。旁边的3000mm长“吊装区”没有误挖为空洞。

保留孔口200mm宽、100mm高翻边及简洁栏杆；楼梯井按各层梯段范围切开，二层24处明确圆形槽罐穿层孔也按原图保留。总装仍可将楼板淡化或隐藏，独立建筑可按层/孔区查看。

## 精度边界

平面位置、房间边线、吊装孔内轮廓和主要楼梯标高以图纸为依据。楼板统一160mm为沿用显示口径，尚未按所有分区结构板厚逐块细化；300×450mm主梁截面沿用原独立外观显示规则，并非逐根配筋模型。上部主体柱段沿用此前模型，仍有待上部结构图逐段复核。没有补造设备、配电柜、家具或未确认的精装细节。

新增建筑构件尚未纳入原总装“桥架与主体柱”的完整施工碰撞校核，不能将原66组穿入/18组表面接触报告理解为覆盖所有新增建筑构件。

## 重建与校验

依赖Python+NumPy、Node.js；静态浏览不需要这些构建依赖。建筑构建工具独立，不调用设备或桥架构建脚本。

```sh
python 厂房外观模型/建筑/tools/project.py build
python 厂房外观模型/建筑/tools/test_building.py
python 厂房外观模型/建筑/tools/project.py check
```

更新预览或浏览器记录后执行 `tools/project.py snapshot` 再检查。浏览器验证使用Playwright/Chromium，先在仓库根启动HTTP服务，再运行 `BUILDING_TEST_URL=http://localhost:8000 python 厂房外观模型/建筑/tools/test_browser.py`。

建筑更新后如需同步总装来源指纹/报告，运行 `python 水解总装工程/tools/project.py build` 并验证浏览。总装的建筑来自同一 `model_data.js`，设备与桥架几何、设备就位表不会因此被自动修改。
