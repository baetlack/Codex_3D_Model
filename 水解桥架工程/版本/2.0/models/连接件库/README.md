# 水解工段连接件独立模型库 v1.2

v1.2仅修正L2-C18偏移方向：局部Y从+850mm改为-850mm，投影长度1175mm及偏移幅值850mm不变。当前包为 `连接件模型库_v1.2.zip`，以下v1.1记录保留用于追溯。

本库包含47个可独立导入的连接件几何初模：第一层9、第二层21、第三层17。模型按截图形状分类，保留原DWG句柄和截图来源；它们还没有装回桥架，也未完成与天正原模型的几何叠合核验。

## 使用

双击 `index.html`，可离线切换47个模型、拖动旋转、滚轮缩放、Shift拖动平移，查看接口及原始截图。不需要联网或安装依赖。

- `glb/`：47个GLB；单位米、Y向上。可用于后续三维交互场景及常见三维软件导入。
- `obj/`：47个OBJ；单位米、Z向上。OBJ不携带标准单位声明，导入时请选米。
- `parameters/`：47份JSON；几何参数、接口位置及法向、原始坐标范围、截图对应关系、待复核项。参数位置单位为毫米，采用局部Z向上坐标。
- `previews/`：47张单件预览和3张分层总览。
- `screenshots/`：47份原始截图副本，与源文件哈希一致。
- `catalog.json`、`模型目录.csv`：模型目录。
- `verification.json`：文件结构、网格及接口检查结果。

局部接口位置是槽底基点，不是截面几何中心。GLB的位置与接口JSON之间需要应用 `(x,y,z) → (x,z,-y)/1000`。GLB已完成该变换。模型均放在局部原点附近，未应用厂房平面位移或楼层偏移。

## 参数来源与精度

水平弯头、水平三通、垂直上下弯、垂直三通和变径的口宽、槽高、L/L1/L2来自截图参数窗；三通不同接口宽度分别保留。坡段与乙字弯的端点差值取自原DWG桥架数据，导出的端点坐标存在约0.5mm的舍入误差。

第三层C14变径为L=600mm、300→500mm、H=200mm；已更正前一轮说明里写成500mm的记录。变径为单侧偏置，斜边分段比例未标注，按参数化过渡构造。

第三层截图编号C02/C03、C04/C05、C07/C08、C15/C17采用建议对调关系；每个参数文件同时保留原截图编号。最终对应仍需装配核验，截图原文件未改名。

## 已知待精化项

- 本版是可浏览、可复用的几何初模。水平弯头L按局部中心线臂长解释、L1/L2按局部总尺寸解释，尚未与天正原对象轮廓逐件叠合。
- 水平内角倒角、乙字弯的折点位置、变径的斜边起止点未有单独尺寸，使用可调整的几何比例。
- 三个垂直三通（模型L3-C02、C04、C15）已按新增三视图重建收口斜面与短颈。C04同时向-Y侧收窄。斜面分段尺寸由已知名义尺寸和正交视图比例推定，仍需与DWG原实体叠合核验。
- 板厚暂用2mm。模型开口、无盖，不含冲孔、法兰、螺栓。底板与侧板保留为相交的独立壳板构造，没有进行实体布尔合并，不是生产加工模型。
- 没有自动采用这些局部模型替换原DWG，也没有修改原图纸。

几何生成源代码位于工作区 `build_fitting_library.py`，可修改CONFIG参数后重新生成模型。生成时保留本目录的离线浏览器文件。
