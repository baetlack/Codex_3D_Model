## 资料如何变成模型

用户提供原版DWG、T3/DXF和连接件截图/三视图。在安装了T30天正电气的AutoCAD中读取原始专业对象：COM导出句柄、宽高、起止标高等属性，AutoLISP导出路径端点。DXF协助识别平面和楼层原点，不能代替原始三维专业对象。

程序以原始路径和对象属性为基础，结合截图尺寸、用户确认和生成公式构造连接件，再适配直段端点，形成三层装配。`data/来源记录.json`、各连接件参数、生成脚本与端点调整报告共同记录依据。截图原件保留；截图编号与模型编号存在交叉对应，修改时必须查映射。

东+X、北+Y、上+Z，本地Z=0对应EL100。参数毫米；OBJ米/Z向上；GLB米/Y向上（东+X、北-Z）。浏览器限定正立并提供东南方向复位。

## 后续修改与复用

请以本目录为唯一维护入口。修改前保存版本；原始资料不覆盖，新资料以新文件名加入，更新来源记录。历史输出仍保留在原工作目录，但不再作为更新入口。

安装Python及 `tools/requirements.txt` 依赖后，在本目录执行：

```powershell
python tools/project.py check
python tools/project.py build
python tools/project.py build-library
node tools/check_viewer.mjs
python tools/project.py snapshot
```

`check`校验几何、接口和当前文件清单；`build`用当前库重建整体并更新主入口；`build-library`明确重建连接件库并随即重建整体。生成在临时目录完成，检查通过才同步。库形状修改须同时更新来源记录。浏览检查需要Node及Chrome，默认Chrome安装路径可在脚本中调整。`snapshot`在确认改动后刷新哈希基准；刷新前先检查差异。启动依赖由本机Python环境提供，不打包虚拟环境。

具体几何参数目前集中于 `tools/source/build_fitting_library.py`，楼层与装配逻辑位于 `build_tray_assembly.py`、`assembly_revision02.py`。**project.json是索引，不是自动驱动全部模型的配置文件**；迁移其他工程须适配这些项目规则及数据，浏览脚本和独立GLB可以复用。

原COM/LISP采集脚本保存在 `tools/source` 作为原始过程记录，含旧工作路径，重新采集应使用 `tools/export_cad.ps1`。需本机AutoCAD2025+T30打开目标原DWG，不对DWG作修改。脚本会先核对图纸名称；用户须另行核对图纸内容/修订版本。

## 当前边界与验证

当前是三层桥架工程，厂房结构、机柜室尚未建模。板厚2mm、部分倒角及端部净空是建模假设；未建孔/盖板/紧固件，薄板交叠未全部布尔合并。直段端点有适配修正，并非原CAD端点冻结复现，详见 `models/整体/reports/endpoint_adjustments.json`。仍有18个自由端。

钛液预热槽 C41B02 已归档至 `../水解设备模型库/设备档案/C41B02_钛液预热槽/`。归档版按 Ø5500×5000mm 和搅拌器高出槽顶2185mm；档案内提供OBJ/GLB、侧视图和交互式三维页面。本目录保留本次建模的工作过程副本。

槽罐搅拌器标注侧视重建 v0.3 见 [独立 3D 页面](models/设备/槽罐搅拌器_标注侧视/index.html)。两处带通孔的轴座与开窗支架一体成形。中间轴两端对称，叶轮独立。本模型按截图比例建立，位号待确认。以 `python tools/project.py build-agitator` 重建 GLB、OBJ、材质和浏览网格。图面读取范围和暂定尺寸见同目录 `参数.json`。

已有几何及接口校验、库文件哈希和浏览器交互检查；未进行完整碰撞检查，不作为施工精度认证。C04侧边对齐采用minX/minY边，是当前可追溯实现选择。

浏览修订1.1：俯仰范围0°～90°，可到水平视角；左右侧栏可独立收起/展开，折叠后保留筛选与选中构件，画布自动扩展。窄屏初次打开时默认收起两栏。几何与连接件库版本保持不变。

文件完整性见 `data/文件清单.json`；工程整理核验见 `data/工程检查.json`。原报告中的本机绝对路径及旧“待补建”文字属于历史快照；当前入口、project.json与来源记录优先。
