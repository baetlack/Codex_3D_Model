# 水解工段三层桥架装配预览 v0.2

槽罐及顶部搅拌器作为独立新增设备模型，见 `../设备/`；不会参与桥架层级或标高显示。

双击本目录 `index.html` 打开离线交互模型。不需要联网、安装依赖或启动服务器。

本版包括64段来自原DWG的桥架、47个已确认的v1.2连接件，以及按用户确认连接关系计算的1个45°乙字弯，共112个构件。三层基准按用户确认采用EL100 / EL106 / EL112；模型坐标Z=0对应EL100。

## 浏览

- 左侧三个楼层按钮切换显示；“并排展开”可分开看三层。
- 拖动旋转、滚轮缩放、Shift拖动平移。俯仰限制为0°～90°，无相机滚转，不能翻到底面。
- “方向复位（东南）”恢复东南轴测、35°俯角；“北向俯视”为上北下南、左西右东。右下角显示地理方向，X东、Y北、Z上。
- 点击构件查看编号、句柄、接口和连接关系；左侧搜索编号或句柄，点击结果可直接聚焦。
- “查看本次连接修订”定位新乙字弯及底板/侧边线对齐的三个连接件。
- “参考标高面”只表示楼层基准矩形，不是已建模的实际楼板。

## 模型文件

- `models/三层桥架.glb` 和 `.obj`：整体模型。
- `models/L1_桥架.glb` 至 `L3_桥架.glb`，以及对应OBJ：分层模型。
- `models/L3-X01_45度乙字弯.glb`、OBJ和`L3-X01_参数.json`：新增乙字弯及计算尺寸。
- GLB为米、Y向上；OBJ为米、Z向上。GLB中保留三层分组和每个构件的名称、原DWG句柄。
- `assembly.json`：构件、坐标、连接件安装变换、连接关系和待核对项；位置与尺寸以毫米记录、Z向上。
- `previews/三层桥架总览.png`：分层和叠放总览。
- `reports/装配说明.html`：可直接打开的装配核对说明。

## 与原始数据的关系

三层按建筑块插入点对齐，原CAD平面基点分别为：

|层|CAD X mm|CAD Y mm|基准EL|
|---|---:|---:|---:|
|1|328715.637589|55336.381225|100|
|2|397595.010869|55336.381225|106|
|3|532950.388811|55336.381225|112|

64段桥架按原DWG空间路径和截面重建。47件连接件取自确认后的模型库，未更改源库文件，未进行几何缩放。L2-C18按安装方向采用局部Y镜像实例，这一变换已单独记录，库内v1.2模型没有改动。

直段端点、长度及朝向按确认的连接规则调整，原始路径仍保留。当前128个直段端点中32个位移超过100mm，最大约765.75mm；详见 `reports/endpoint_adjustments.json`。本次新增的是用户明确确认的跨层竖管接续和立管乙字弯。

## 接触对齐规则

|连接件|接口|相邻直段|确认后的对齐|
|---|---|---|---|
|L3-C03|A|37C27|底板对齐，中心不重合|
|L3-C04|C|37C74|同侧边线对齐（出口与竖管的最小X、最小Y边线）|
|L3-C17|A|37C21|底板对齐，中心不重合|

截面尺寸差异保留，按用户指定的底板或边线建立接触，而非强制中心相同。相关规则和接触点写入assembly.json，接触点间隙校验通过。

## 东南竖管与新增乙字弯

L3-S-37C11已转正90°，与L2-S-37C18同轴、同槽口朝向，在EL112接续为同一条竖管。

L3-X01连接L3-S-37C11和L3-S-37C12，截面500×200mm；中间斜段水平偏移971.03mm、升高971.03mm，倾角严格45°；两端各150mm竖直段，接口总高差1271.03mm。为满足45°并容纳折角，37C11上端裁短到EL115.42897，另一接口为EL116.70000。具体端点坐标与尺寸在新增模型JSON中保留。

## 校验

`reports/verification.json`记录112个构件、47件库模型保形、110条连接、底板/侧边接触、同轴竖管与45°角检查，以及全部5个GLB的文件结构/面/法向检查。不包括全场碰撞检测。

`reports/browser_check.json`记录Chrome交互测试：北向投影、东南方向复位、防翻转角度限制、跨层连接导航、选中、楼层隔离、搜索、显示切换、并排展开、鼠标旋转与滚轮缩放均通过，无未捕获异常。

生成源代码位于工作区 `build_tray_assembly.py`、`assembly_revision02.py`；不会改写原DWG、DXF或连接件模型库。v0.1压缩包仍保留，当前目录及v0.2压缩包为修订结果。
