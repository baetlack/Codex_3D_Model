# 水解总装工程 v0.3

将厂房、112 个桥架构件与正式设备模型组合在同一三维坐标中。源模型保持独立维护，备用设备模型不作为总装几何来源。无外网脚本、无 CDN，所有资源随仓库提供。

## 打开与浏览

推荐在仓库根目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000/水解总装工程/`。当前测试环境的浏览器策略禁止 file:// 导航，未验证双击打开；本地 HTTP 浏览已通过。

默认显示厂房完整外观；“内部总览”切换透明外墙并隐藏屋面。支持模块开关、位号搜索、选中聚焦、北向俯视、EL 标高区间、水平上剖切、设备标签，以及点击相交项同时高亮两个构件。拖动旋转，Shift 拖动平移，滚轮缩放。东南复位俯角3°，无滚转，俯角限制0–90°。上剖切默认 EL150，完整包含高位烟囱，避免默认截断屋面以上设备。

建筑视觉统一引用 `../厂房外观模型/建筑/building_style.js`，采用深色背景、灰蓝墙面、青色门窗轮廓和弱化梁柱网格。仅覆盖建筑显示材质、灯光和默认相机，设备与桥架材质及全部模型网格、就位数据不变。

工具栏新增“测量尺寸”：支持两点距离/净距、竖向高差与楼层标高层高、柱轴中心距、构件包络尺寸。支持角点/边线/剖切交点吸附、mm/m切换、撤销与清空。仅测量建筑；透明外墙可穿透拾取，柱轴模式穿透淡化楼板，隐藏或裁切构件不参与新测点拾取。测量直接使用共享建筑毫米坐标，独立建筑与总装读数一致，不修改设备、桥架或结构数据。操作说明与测试记录见 [建筑测量说明](../厂房外观模型/建筑/README.md)。

共享建筑新增二层3处、三层11处明确标注的楼面开孔（含5处φ500预留孔）。大孔翻边与栏杆沿用现有吊装孔风格，小孔按图保留翻边。原有孔洞、柱梁、楼梯、房间、设备及桥架的位置和形状不变，详见建筑模块的 `data/楼板开孔依据.json`。

## 坐标与安装依据

统一东 +X、北 +Y、上 +Z，数据毫米制，`Z=0` 对应 EL100；厂房 +6/+12/+23 m 对应 EL106/112/123。

- 完整建筑在其独立源模块中已归一到柱轴坐标；总装直接引用 `../厂房外观模型/建筑/model_data.js`，不再平移，也不另造简化版。
- 桥架原模型以建筑块轴网原点装配，无额外平移、旋转或缩放。原图建筑块8列轴线与结构柱轴一致，44 m ×72 m范围一致。
- 设备取原始布置 DXF 的实体图块或明确圆轮廓中心，保留图块句柄、对应位号、来源楼层原点及旋转角。不将位号文字插入点当成设备中心。
- 23 台主要槽罐与建筑基础独立对照：22 台误差小于1 mm。D41B02B1 原布置图块偏离建筑基础约200.22 mm，总装按建筑基础中心修正；原始图纸未修改。详见 `data/对齐依据.json`。
- 水解槽本体底 EL101.500；偏钛酸缓冲槽本体底 EL100.300；钛液预热槽本体底 EL112.150，纠正旧清单把它归到EL100的记录。
- 冷却器模型托耳与 EL104.500 钢框架承托面对应，不能将整机模型再抬高4.5 m。
- 晶种槽以承托面 EL111.000 和模型承托安装差1180 mm换算本体模型原点；配对朝向已按平面图块镜像及七处顶口对应核对，净模尺寸不变。

## 相交检查

`data/碰撞报告.json` 保存272个检查对象的跨模块结果；`data/桥架立柱核对.json` 是桥架与粗柱的专项报告。当前默认引用桥架2.0，主体柱范围0组穿入、18组正常表面接触。扩展到全部120根柱后仍为0组穿入；整改前1.0的69组明细已冻结保留。

桥架与柱先用包围盒筛选，再把真实三角面裁剪到柱体的开内部；只有进入内部才报穿入。数值接触容差0.1mm。报告记录构件/柱编号、进入柱体的三角面、内部证据点及该点距柱面的深度；该深度是证据点深度，不是要求移动桥架的距离。棱角接触即使包围盒重叠很大，也不误列为穿入。

界面“穿入项”默认显示桥架与立柱，可切换“表面接触（正常）”或全部对象。点击条目直接放大并隔离对应局部，桥架为金色、立柱为红色；“隔离选中”可恢复周围环境。桥架2.0经用户授权按柱外轮廓整改，连接件仅刚性平移、直段联动；建筑与设备保持。其他对象继续采用三角形检测及闭合部件包含检查，已确认桥架接续和设备基础承托不列入报错；淡化显示楼板不参与施工碰撞定论。

## 重建与校验

Python依赖见 `requirements.txt`。在仓库根目录运行：

```sh
python 水解总装工程/tools/project.py build
python 水解总装工程/tools/project.py check
python 水解总装工程/tools/test_geometry.py
python 水解总装工程/tools/test_revision.py
python 水解桥架工程/tools/project.py check
```

`build` 更新总装就位表、建筑展示网格、对齐依据、相交结果及总装SHA256快照；不改源图或源模型。源文件指纹见 `data/来源与哈希.json`。`data/浏览器检查.json` 记录当前版本交互验证，截图见 `previews/`。浏览器复验需安装 Playwright 和 Chromium；在仓库根目录启动 `python -m http.server 8765` 后，运行 `python 水解总装工程/tools/test_browser.py`。新几何构建后浏览器证据需重新验证。

建筑只在“厂房外观模型”维护，`data/building.js` 仅为共享网格别名。设备及桥架几何与设备就位表本次保持不变。

文件职责：`assembly.json` 为模块引用与刚性变换；`data/设备就位表.json` 为逐台依据；`data/待核设备.json` 为未装入项；`viewer.js` 仅负责加载、显示、剖切与选择，不写回源模型。
