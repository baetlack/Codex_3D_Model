# 水解总装工程 v0.1

将厂房、112 个桥架构件与正式设备模型组合在同一三维坐标中。源模型保持独立维护，备用设备模型不作为总装几何来源。无外网脚本、无 CDN，所有资源随仓库提供。

## 打开与浏览

推荐在仓库根目录运行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000/水解总装工程/`。当前测试环境的浏览器策略禁止 file:// 导航，未验证双击打开；本地 HTTP 浏览已通过。

默认显示厂房完整外观；“内部总览”切换透明外墙并隐藏屋面。支持模块开关、位号搜索、选中聚焦、北向俯视、EL 标高区间、水平上剖切、设备标签，以及点击相交项同时高亮两个构件。拖动旋转，Shift 拖动平移，滚轮缩放。东南复位俯角35°，无滚转，俯角限制0–90°。上剖切默认 EL150，完整包含高位烟囱，避免默认截断屋面以上设备。

## 坐标与安装依据

统一东 +X、北 +Y、上 +Z，数据毫米制，`Z=0` 对应 EL100；厂房 +6/+12/+23 m 对应 EL106/112/123。

- 厂房外墙边界坐标转柱轴坐标：X、Y 各减325 mm；柱位已在轴网坐标中，不再平移。
- 桥架原模型以建筑块轴网原点装配，无额外平移、旋转或缩放。原图建筑块8列轴线与结构柱轴一致，44 m ×72 m范围一致。
- 设备取原始布置 DXF 的实体图块或明确圆轮廓中心，保留图块句柄、对应位号、来源楼层原点及旋转角。不将位号文字插入点当成设备中心。
- 23 台主要槽罐与建筑基础独立对照：22 台误差小于1 mm。D41B02B1 原布置图块偏离建筑基础约200.22 mm，总装按建筑基础中心修正；原始图纸未修改。详见 `data/对齐依据.json`。
- 水解槽本体底 EL101.500；偏钛酸缓冲槽本体底 EL100.300；钛液预热槽本体底 EL112.150，纠正旧清单把它归到EL100的记录。
- 冷却器模型托耳与 EL104.500 钢框架承托面对应，不能将整机模型再抬高4.5 m。
- 晶种槽以承托面 EL111.000 和模型承托安装差1180 mm换算本体模型原点；配对朝向沿用平面图块记录，管口对应仍需核对。

## 当前覆盖与待核项

99 台设备全部记入清单：72 台已取得可关联的平面图块/圆轮廓并装入，其中44台有明确安装标高依据，28台的安装基准仍待核，以暖色提示。27台暂未装入空间场景，清单可搜索查看，未使用旧预览的文字坐标补位。

平面中心有依据不代表所有管口方向均已确认。图块插入基准与复杂设备局部原点的对应、管口朝向、部分安装高差须继续逐项核对。总装第一版用于视觉位置复核，尚不能宣称全部设备位置校验完成。

厂房门窗沿用已核对的立面数据。外墙厚200 mm、屋面厚200 mm仅用于展示，不参与碰撞定论。柱位、截面沿用源模型；+9.900 m以上柱截面尚待上部结构图复核。缺少真实截面和开孔资料的梁板不补画，因此梁板碰撞暂未覆盖。不考虑检修空间。

## 相交检查

`data/碰撞报告.json` 保存282个检查对象的跨模块检查结果：97组包围盒候选，75项几何相交待复核，另有18项包围盒重叠小于1 mm的接触候选。先用AABB筛选，再做三角形分离轴检测；对于无表面交叉的包含情况，检查闭合部件的射线包含。不会将包围盒重叠直接认定为碰撞。

检查桥架与设备/柱、设备与柱、设备与设备。桥架内部已确认的连接与设备基础正常承托不列入报错。几何相交不自动认定施工冲突，须结合安装基准、示意几何与正常接触关系复核。报告保留两件编号、三角形证据、候选位置及待核安装状态。

## 重建与校验

Python依赖见 `requirements.txt`。在仓库根目录运行：

```sh
python 水解总装工程/tools/project.py build
python 水解总装工程/tools/project.py check
python 水解总装工程/tools/test_geometry.py
python 水解桥架工程/tools/project.py check
```

`build` 更新总装就位表、建筑展示网格、对齐依据、相交结果及总装SHA256快照；不改源图或源模型。源文件指纹见 `data/来源与哈希.json`。`data/浏览器检查.json` 记录当前版本交互验证，截图见 `previews/`。浏览器复验需安装 Playwright 和 Chromium；在仓库根目录启动 `python -m http.server 8765` 后，运行 `python 水解总装工程/tools/test_browser.py`。新几何构建后浏览器证据需重新验证。

文件职责：`assembly.json` 为模块引用与刚性变换；`data/设备就位表.json` 为逐台依据；`data/待核设备.json` 为未装入项；`viewer.js` 仅负责加载、显示、剖切与选择，不写回源模型。
