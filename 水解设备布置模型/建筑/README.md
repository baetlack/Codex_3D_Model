# 水解厂房建筑与设备布置模型

## 浏览入口

- `index.html`：厂房外观。四面门位和窗位均按建筑立面核对：133扇窗（东33、西30、南35、北35），13樘门（东2、西5、南3、北3）。东立面另按截图补入11处在DXF中未作为独立INSERT的窗洞，尺寸与窗台/窗顶按相邻同型窗和轴网节奏对应。外墙和屋面均为不透光实体面；窗为简洁十字分格，工业门有下部交叉网格和宽门内嵌小门，省略阴影细节。两处屋面楼梯间四周封墙并设实心顶板；竖向转角和屋顶周边采用统一的低对比边线。复位与连接件浏览器一致：yaw −45°、俯仰35°、东南方向；可拖动旋转，俯仰限制0–90°，右下角方向标有东南西北。
- `楼层叠加总览.html`：厂房框架视图，展示柱梁及屋顶楼梯间轮廓。

## 建筑与结构数据

- 建筑结构轴网范围为 44,000 × 72,000 mm；建筑平面外墙边界为 44,650 × 72,650 mm。坐标东 +X、北 +Y、上 +Z。
- 一至四层地面标高为 0、+6,000、+12,000、+23,000 mm。屋面四周为厚 300 mm 的女儿墙，墙顶 +24,500 mm。西南角与东北角的楼梯间外轮廓各为 3,425 × 7,850 mm，顶标高 +26,900 mm，以封闭体块表达。平面尺寸与标高记录在 `主体尺寸.json`。
- `立面门窗数据.json` / `.js`：窗块提供精确窗位、宽度、窗台和窗顶标高；东立面按用户截图校正为33窗，另补入11处DXF未单独成块但截图可见的重复窗洞。西立面按外侧截图方向将整组门窗水平镜像；南、北两端整体互换。南面 M4848 大门按块图样表达，含双扇分格、上部四扇小窗和左扇人员门，按用户要求省去门扇斜线。西面 m3036 大门按块图样表达，含5列×3行百叶窗、约800 mm高底部网格和靠中缝的人员门。南门块高4,800 mm，底标高+200 mm；西门块高3,600 mm，底标高+300 mm。立面映射为东33窗/2门、西30窗/5门、南35窗/3门、北35窗/3门。门高根据立面可读标注设置，后续有门窗表时可再核。
- `结构立柱数据.json` / `.js`：从《结构施工图》“5.970m~9.900m柱平面布置图”的闭合 `COLU` 轮廓提取 98 根柱的中心坐标与截面：70 根 650×650 mm、18 根 750×750 mm、10 根 400×400 mm。平面轴网归一到建筑东南角局部坐标。
- 结构图明确显示基础顶面至 +5.970 m、+5.970 至 +9.900 m 两个标高段；叠加页将柱位连续表达至屋面 +23.000 m，便于观察设备关系。+9.900 m 以上柱段截面和局部变化尚需依据上部柱平面逐项复核，模型说明中已标注这一限制。
- 设备基础坐标按各层平面图西南角归一。一层基础 26 个圆形和20个多边形；三层23个圆形和4个多边形；二层48个圆形作为一层槽罐顶部参考，不生成二层底座。8个偏钛酸缓冲槽位于东侧，约 X=35,325 mm，沿南北方向布置。
- 基础展示厚度暂设500 mm，仅为可视化假设；后续需按基础剖面/详图确认。
