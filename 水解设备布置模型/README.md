# 水解工段设备布置 3D 模型

带搅拌槽罐的布置预览使用标注侧视搅拌总成的简化网格，按各槽型的搅拌高度放置。详细分件可在设备模型库中打开。

打开 `index.html` 离线浏览。支持旋转、缩放、按标高筛选、搜索位号和查看设备台账规格。

## 输入资料
- `设备/` 下各类槽罐、冷却器、塔器和电动葫芦的俯视/侧视截图：设备几何模板和细节依据。
- `3.水解工段设备布置图+2026.5.21.dxf`：四个平面、I-I/II-II/III-III剖视、设备位号、轴网间距与 POS EL 标注。
- `2.水解水洗设备一览表 2026.8.12.xlsx`：“水解”页提供设备名称、规格、数量和葫芦起升高度。

## 本版校正
- 电动葫芦按侧视图作为梁下小型行走小车/吊钩建模；台账的6/12/24m是起升高度，不再作为设备实体高度。
- 按设备完整位号后缀建立实例并去掉剖面重复标注；当前94个图纸位号实例，其中三组偏钛酸冷却器各表示一对冷却单元（合计6台）。
- 圆槽罐依设备类型区分平顶储槽、带搅拌驱动槽、带支腿水解槽、锥底晶种槽；冷却器按成对平台布置；塔器、过滤器、泵、地下池和葫芦各有独立简化结构。
- 平面图按图题横向平移量归一后叠加；设备底标高优先按 POS EL 和剖面标高关系设置。坐标仍需按轴网复核。

设备外形按截图和剖视比例简化，未还原内部盘管、喷淋管、螺栓等细节；设备位号点用于定位，不保证等于设备中心。模型用于方案沟通，不用于施工放样或设备基础设计。逐台数据和依据见 `设备数据.json`。
# 设备几何与颜色约定补充

偏钛酸缓冲槽 F41B01 按台账 Ø5000×5900 建模；水解槽 D41B02 按 Ø5900×4700 建模。图纸截图的设备配色映射为：青色槽体、红色混凝土基础、白色钢支撑及顶部搅拌驱动。缓冲槽的顶部搅拌是独立的小型构件，不计入槽体高度；其基础与支撑单独绘制。
# 几何显示补充

D41B02 本体尺寸固定为 Ø5900×4700 mm；本体圆柱直径大于高度，呈宽短罐体。F41B01 偏钛酸缓冲槽按台账为 Ø5000×5900 mm。模型显示中移除了三角面密集描边，红色基础不再绘制顶面，仅显示低矮基础边和基础墩，避免遮挡青色槽体。

## 设备清单

`设备清单.csv` 按设备模型目录 `../水解设备模型库/catalog.json` 导出，共99条设备记录，含设备名称、位号、位号组、台账规格、台账组数量、模型几何尺寸、楼层/POS EL、DXF定位坐标、定位状态及高度依据。设备一览表原始Excel未放入当前工作区；模型目录记录其来源为“2.水解水洗设备一览表 2026.8.12.xlsx”。CSV保留台账规格文本；外形尺寸和坐标分别标作模型/布置数据。94条布置实例见本目录 `设备数据.json`，与99条设备模型记录口径不同。

使用 `tools/export_equipment_list.py` 可从设备库目录重新导出清单。C41B02 本次确认类型模型单独归档在 `../水解设备模型库/设备档案/C41B02_钛液预热槽/`；既有 C41B02A–E 几何文件保留不覆盖。
